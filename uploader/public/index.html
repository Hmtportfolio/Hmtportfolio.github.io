Where do I find these credentials in Cloudflare?
  1. Go to Cloudflare Dashboard → R2.
  2. Your Account ID is displayed on the right sidebar of the R2 overview.
  3. Click Manage R2 API Tokens on the right sidebar → Create API token.
  4. Select Object Read & Write permissions, choose your bucket, and click Create API Token.
  5. Copy the Access Key ID and Secret Access Key into this form!
  6. In your bucket settings, ensure R2.dev subdomain or Custom Domain is enabled to get public links.
